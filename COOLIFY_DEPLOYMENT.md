# Инструкция по деплою игры «Мама, я богат!» в Coolify

Coolify — это современная, функциональная self-hosted альтернатива Netlify, Heroku и Vercel, позволяющая в несколько кликов разворачивать приложения, базы данных и сервисы на собственных серверах с автоматическим выпуском SSL-сертификатов (Let's Encrypt) и встроенной поддержкой WebSockets.

Наше fullstack-приложение написано на Node.js (Express + React) и использует WebSocket-соединение (`Socket.io`) для синхронизации игроков на одном игровом столе. Coolify поддерживает деплой таких приложений двумя способами: с помощью **Nixpacks** (рекомендуемый простой способ без написания Dockerfile) и с помощью **Dockerfile**.

---

### Подготовка (Основные принципы)
* По умолчанию приложение слушает сетевой порт **3000** на хосте `0.0.0.0` (это стандартные и жесткие настройки нашего сервера).
* Coolify автоматически выполнит обратный прокси-сервер (Traefik или Caddy) для вашего домена и настроит автоматический редирект на HTTPS, а также прокинет туннель для WebSocket-пакетов.

## Способ 1. Автоматический деплой через Nixpacks (Рекомендуемый)

**Nixpacks** — это современная утилита автоматического определения стека технологий и сборки контейнеров, используемая в Coolify по умолчанию. Она сама поймет, что проект работает на Node.js, установит зависимости, запустит сборку и старт.

### Шаг 1. Подключение репозитория в Coolify
1. Зайдите в панель управления **Coolify**.
2. Перейдите во вкладку **Sources** и убедитесь, что ваш аккаунт GitHub/GitLab подключен. Если нет, подключите его.
3. Перейдите к вашему **Project** -> **Environment** (например, `production`) и нажмите кнопку **+ New Resource**.
4. Выберите пункт **Private Repository (GitHub / Git)** или **Public Repository**.
5. Выберите репозиторий с вашей игрой и укажите ветку сборки (например, `main` или `master`).

### Шаг 2. Настройка конфигурации проекта
После инициализации Coolify переведет вас на страницу настроек приложения. Укажите следующие параметры настроек:

* **Build Pack:** Выберите `Nixpacks`.
* **Ports Exposes:** Укажите порт `3000`.
* **Domains:** Введите ваш домен или поддомен. Например: `https://game.yourdomain.com`. 
  > *Жирный плюс Coolify: Указание схем `https://` автоматически сгенерирует и прикрепит бесплатный SSL-сертификат Let's Encrypt за считанные секунды.*

### Шаг 3. Запуск веб-сборки
Coolify и Nixpacks автоматически выполнят следующие фазы сборки:
1. Выявление среды: Обнаружение модульного окружения Node.js из `package.json`.
2. Копирование и запуск `npm install` для скачивания пакетов.
3. Выполнение команды `"build"` из нашего файла настроек: `vite build && esbuild server.ts --bundle --platform=node ...`. Это скомпилирует клиентские страницы в папку `/dist` и сервер бэкенда в `/dist/server.cjs`.
4. Запуск бэкенд сервер-процесса командой `"start"`: `node dist/server.cjs`.

Нажмите кнопку **Deploy** в правом верхнем углу. Ваше приложение успешно соберется и запустится!

## Способ 2. Деплой через Dockerfile

Если вы предпочитаете иметь полный и гарантированный контроль над контейнером сборки вашего приложения, вы можете использовать Docker. Для этого создайте в корне вашего проекта текстовый файл с именем `Dockerfile`:

### 1. Создание Dockerfile в корне проекта
```dockerfile
# --- Этап 1: Сборка статических файлов и сервера бэкенда ---
FROM node:20-alpine AS builder
WORKDIR /app

# Копирование файлов дескрипторов
copy package*.json ./

# Установка всех зависимостей сборки
RUN npm ci

# Копирование исходного кода приложения
COPY . .

# Проведение оптимизированного полного билда
RUN npm run build

# --- Этап 2: Финальный легковесный образ для выполнения ---
FROM node:20-alpine AS runner
WORKDIR /app
ENV NODE_ENV=production

# Копирование пакетов только для Production и собранного дистрибутива
COPY package*.json ./
RUN npm ci --only=production

# Перемещение папки dist, собранной на первом этапе
COPY --from=builder /app/dist ./dist
# Копирование дополнительного кэша баз данных макетов, если они используются
COPY --from=builder /app/data ./data

# Открытие портов наружу
EXPOSE 3000

# Запуск приложения
CMD ["node", "dist/server.cjs"]
```

### 2. Применение Dockerfile в Coolify
1. Залейте изменения `Dockerfile` в ваш репозиторий Git.
2. В панели приложения Coolify в настройках конфигурации найдите строку **Build Pack**.
3. Измените значение с `Nixpacks` на `Dockerfile`.
4. В поле **Port Expose** (если оно изменилось) оставьте `3000`.
5. Нажмите кнопку **Save** и затем кликните **Deploy**.

## Преимущества работы игры в Coolify
* **Для WebSockets (Socket.io) не нужны дополнительные плагины:** Прокси-сервер (Traefik/Caddy), встроенный в Coolify, «из коробки» правильно обрабатывает заголовки `Upgrade` и `Connection`, предотвращая обрывы соединений игроков со столами.
* **Автоматические бэкапы бэкенд-файлов:** Если вы вносите изменения в правила, темы или карты через Панель Администратора, они пишутся в локальный JSON-файл в корневой директории `/data` (локальная база данных проекта). Чтобы эти изменения не стирались при каждом новом деплое игры:
  1. В панели настроек приложения выберите вкладку **Storages / Volumes**.
  2. Нажмите **+ Add Storage**.
  3. Укажите тип хранилища: `Local Folder / Volume`.
  4. Путь на хосте (Source): останется сгенерированным по умолчанию.
  5. Путь внутри контейнера (Destination): Укажите `/app/data` (или `/data` в зависимости от того, где лежит папка базы данных по логам).
  6. Нажмите **Save**. С этого момента конфигурация ваших измененных карт и тем никогда не потеряется при сборке новых версий!
* **Анализ логов:** Во вкладке **Logs** вы можете прямо в GUI отслеживать подключение клиентов, активацию игровых карт и логгировать события.
